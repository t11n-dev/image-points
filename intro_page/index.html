Capabilities

Loaded with Premium Features

Drag & Drop Admin

Place pins intuitively inside the WordPress edit page. Pixels automatically translate to perfectly precise percentage values.

Rich Tooltips

Fully supports custom HTML content inside tooltips. TinyMCE visual editor is fully integrated for beautiful texts, lists, links, or media.

100% Responsive

Absolute percentage coordinates ensure that no matter the viewport, screen size or orientation, your pins stay exactly where they belong.

Smart Placement

Tooltips detect viewport boundaries dynamically and auto-correct their rendering position to avoid overflow or clipping on mobile devices.

Interactive Pulse

Optional subtle pulse hover/focus animation cues dynamically draw the visitor's attention to the most important points on your layouts.

Lightweight Code
